# dotsync Preservation Subsystem — Implementation Plan (Plan 2 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `dotsync` — a generic, manifest-driven preservation subsystem that makes it hard for any config to fall through the cracks between the two repos. It discovers repos and their tracked targets from manifest fragments (never hardcoding the work repo), reports orphans/conflicts/missing targets (`check`), shows VCS state (`status`), backs up the whole laptop in one command (`sync`), and materializes a human-readable ownership map (`inventory`).

**Architecture:** `dotsync` is a single zero-dependency Node CLI deployed by chezmoi to `~/.local/bin/dotsync`. It is split into a **pure core** (manifest parse, tilde-expand, derived target sets, orphan/conflict computation, inventory render, sync-plan computation) and a thin **IO shell** (a `runner` that spawns `chezmoi`/`git`, plus filesystem scans and the arg dispatcher). The core takes an injectable `runner` and explicit roots, so tests drive it with fixtures and a fake runner rather than mutating the real system. The manifest is JSON fragments merged in lexical order. Target sets are **derived** (`chezmoi managed` / `git ls-files`), never hand-listed, so the ownership map cannot drift.

**Tech Stack:** Node (builtins only — `node:fs`, `node:path`, `node:os`, `node:child_process`; no npm installs), run via plain `node tests/*.test.js` assert scripts matching the repo's existing tests. chezmoi (deploys the CLI + general manifest fragment), git.

**Spec:** `docs/superpowers/specs/2026-06-28-dotfiles-two-repo-split-design.md` (sections "Preservation subsystem: `dotsync`" and the manifest schema).

**Scope note:** This is Plan 2. Plan 1 (the split) has shipped: two repos exist — the general chezmoi repo at `~/.local/share/chezmoi` (source root `home/`, on `main`) and the private work repo at `~/work-laptop-config` (symlink-deployed via its `install.sh`, payload roots `.claude` and `.config`). The work repo already ships `~/work-laptop-config/.config/dotsync/manifest.d/50-work.json` (symlinked to `~/.config/dotsync/manifest.d/50-work.json`). This plan consumes those and adds the general fragment + the tool.

## Global Constraints

- Commit signing is on (1Password SSH agent). Never pass `--no-verify`. Default branch `main` in each repo; prefer rebase/fast-forward. Create new commits (do not amend).
- **Do NOT push from task steps.** A single final task (Task 5) pushes both repos.
- chezmoi source root is `home/` (via `.chezmoiroot`). Deployable entries go under `home/`; `docs/`, `tests/` stay at repo top level (not deployed). chezmoi name encoding: `executable_` → +x, `dot_` → `.`. The CLI source path is `home/dot_local/bin/executable_dotsync` → deployed to `~/.local/bin/dotsync` (on PATH).
- **Zero dependencies.** Node builtins only; no `package.json`, no `npm install`. Shebang `#!/usr/bin/env node`.
- **The manifest is JSON** (not TOML — the spec sketch shows TOML, but Plan 1 shipped JSON fragments and the live `50-work.json` is JSON; JSON is the source of truth). Fragments at `~/.config/dotsync/manifest.d/*.json`, merged in lexical order.
- **Core/IO separation is mandatory.** All pure logic (manifest merge, tilde-expand, target derivation given runner output, orphan/conflict/missing computation, inventory render, sync-plan) lives in functions that take their inputs as arguments (including an injectable `runner`), so tests exercise them with fixtures + a fake runner. The CLI dispatcher and the real `child_process` runner are the only IO; they are exercised by the live smoke task (Task 5), not unit tests.
- `sync` and the live `chezmoi apply` are run by the controller (sandbox-gated). Task steps verify via read-only commands (`--dry-run`, `chezmoi cat`, `git status`) where possible; tests never push, never call the real `chezmoi`/`git`.
- Tilde-expansion: a leading `~` or `~/` in any manifest path expands to `os.homedir()`. Derived target paths are always absolute under `$HOME`.

The CLI file `executable_dotsync` defines and exports these. Signatures are fixed; tasks must use them verbatim.

```

// A runner abstracts spawning. Real one uses child_process; fake one returns fixtures.
//   runner(cmd: string, args: string[], opts?: {cwd?: string}) -> { code: number, stdout: string, stderr: string }
makeRealRunner() -> runner

// --- pure core -------------------------------------------------------------

   -> { repos: Repo[], ignoreGlobs: string[] }         // Repo = {name,type,path(abs),remote,roots?}
globToRegExp(glob: string) -> RegExp                   // supports * (one segment) and ** (any)
matchesAnyGlob(absPath, globs: string[], home) -> bool // globs tilde-expanded before match

deriveTargets(repo: Repo, home: string, runner) -> { targets: string[], errors: string[] }
   // chezmoi:     runner('chezmoi',['managed','--include=files']) ; rel-to-$HOME -> absolute
   // git-symlink: runner('git',['-C',repo.path,'ls-files']) ; keep entries under repo.roots ;
   //              map <relpath> -> $HOME/<relpath>
buildOwnership(repos, home, runner)
   -> { ownerByPath: Map<abs,string[]>, targetsByRepo: Map<name,string[]>,
        errorsByRepo: Map<name,string[]> }

scanRoots(home, runner) -> string[]                    // existing files under the scanned roots (IO; uses runner('find',...))
computeCheck({ ownership, existing, ignoreGlobs, home })
   -> { orphans: string[], conflicts: {path,repos[]}[], missing: {path,repo}[] }
       // orphan   = existing file in no repo's targets AND matching no ignore glob
       // conflict = path claimed by >= 2 repos
       // missing  = a declared target with no file on disk
renderInventory(ownership, home) -> string             // INVENTORY.md text (path -> owning repo, sorted)
buildSyncPlan(repos, { force, hasOrphans }) -> { blocked: bool, actions: Action[] }
   // Action = { repo, type, steps: string[] }  -- steps are human-readable command descriptions
   //   chezmoi:     ['chezmoi re-add', 'git commit (if changes)', 'git push']
   //   git-symlink: ['git add -A',     'git commit (if changes)', 'git push']
   //   blocked = hasOrphans && !force

// --- command handlers (return exit code; print to console) -----------------
cmdCheck({ home, manifestDir, runner }) -> number       // 0 clean; 1 orphans/conflicts/missing
cmdStatus({ home, manifestDir, runner }) -> number
cmdInventory({ home, manifestDir, runner }) -> number   // writes ~/.config/dotsync/INVENTORY.md
cmdSync({ home, manifestDir, runner, force, dryRun }) -> number
main(argv, env, runner) -> number                       // arg dispatch
```

```js
#!/usr/bin/env node
// dotsync — manifest-driven dotfiles preservation subsystem (zero deps; node builtins only).
// Pure core is separated from IO (the injectable `runner`) so it is unit-testable with fixtures.
'use strict';

const fs = require('node:fs');
const os = require('node:os');
const path = require('node:path');
const { spawnSync } = require('node:child_process');

const MANIFEST_DIR_DEFAULT = '~/.config/dotsync/manifest.d';
const INVENTORY_PATH = '~/.config/dotsync/INVENTORY.md';

// ---- IO boundary -----------------------------------------------------------
function makeRealRunner() {
  return (cmd, args, opts = {}) => {
    const r = spawnSync(cmd, args, { encoding: 'utf8', cwd: opts.cwd, maxBuffer: 64 * 1024 * 1024 });
    return { code: r.status == null ? 1 : r.status, stdout: r.stdout || '', stderr: r.stderr || '' };
  };
}

// ---- pure core -------------------------------------------------------------
function expandTilde(p, home) {
  if (p === '~') return home;
  if (p.startsWith('~/')) return path.join(home, p.slice(2));
  return p;
}

function loadManifest(dir, home) {
  const repos = [];
  let ignoreGlobs = [];
  let names = [];
  try { names = fs.readdirSync(dir).filter((f) => f.endsWith('.json')).sort(); } catch { names = []; }
  for (const name of names) {
    const raw = JSON.parse(fs.readFileSync(path.join(dir, name), 'utf8'));
    if (raw.repo) {
      const r = raw.repo;
      repos.push({ name: r.name, type: r.type, path: expandTilde(r.path, home), remote: r.remote, roots: r.roots });
    }
    if (raw.ignore && Array.isArray(raw.ignore.globs)) ignoreGlobs = ignoreGlobs.concat(raw.ignore.globs);
  }
  return { repos, ignoreGlobs };
}

function globToRegExp(glob) {
  // ** -> any chars (incl. /); * -> one path segment (no /). Other regex chars escaped.
  let re = '';
  for (let i = 0; i < glob.length; i++) {
    const c = glob[i];
    if (c === '*') {
      if (glob[i + 1] === '*') { re += '.*'; i++; } else { re += '[^/]*'; }
    } else if ('.+?^${}()|[]\\'.includes(c)) {
      re += '\\' + c;
    } else {
      re += c;
    }
  }
  return new RegExp('^' + re + '$');
}

function matchesAnyGlob(absPath, globs, home) {
  return globs.some((g) => globToRegExp(expandTilde(g, home)).test(absPath));
}

function deriveTargets(repo, home, runner) {
  const errors = [];
  let targets = [];
  if (repo.type === 'chezmoi') {
    const r = runner('chezmoi', ['managed', '--include=files']);
    if (r.code !== 0) { errors.push(`chezmoi managed failed: ${r.stderr.trim()}`); return { targets, errors }; }
    targets = r.stdout.split('\n').map((s) => s.trim()).filter(Boolean).map((rel) => path.join(home, rel));
  } else if (repo.type === 'git-symlink') {
    const r = runner('git', ['-C', repo.path, 'ls-files']);
    if (r.code !== 0) { errors.push(`git ls-files failed: ${r.stderr.trim()}`); return { targets, errors }; }
    const roots = repo.roots || [];
    targets = r.stdout.split('\n').map((s) => s.trim()).filter(Boolean)
      .filter((rel) => roots.some((root) => rel === root || rel.startsWith(root + '/')))
      .map((rel) => path.join(home, rel));
  } else {
    errors.push(`unknown repo type: ${repo.type}`);
  }
  return { targets, errors };
}

function buildOwnership(repos, home, runner) {
  const ownerByPath = new Map();
  const targetsByRepo = new Map();
  const errorsByRepo = new Map();
  for (const repo of repos) {
    const { targets, errors } = deriveTargets(repo, home, runner);
    targetsByRepo.set(repo.name, targets);
    errorsByRepo.set(repo.name, errors);
    for (const t of targets) {
      const owners = ownerByPath.get(t) || [];
      if (!owners.includes(repo.name)) owners.push(repo.name);
      ownerByPath.set(t, owners);
    }
  }
  return { ownerByPath, targetsByRepo, errorsByRepo };
}

function computeCheck({ ownership, existing, ignoreGlobs, home }) {
  const owned = ownership.ownerByPath;
  const orphans = existing
    .filter((p) => !owned.has(p) && !matchesAnyGlob(p, ignoreGlobs, home))
    .sort();
  const conflicts = [];
  for (const [p, repos] of owned) {
    if (repos.length >= 2) conflicts.push({ path: p, repos: [...repos].sort() });
  }
  conflicts.sort((a, b) => a.path.localeCompare(b.path));
  const existingSet = new Set(existing);
  const missing = [];
  for (const [name, targets] of ownership.targetsByRepo) {
    for (const t of targets) if (!existingSet.has(t)) missing.push({ path: t, repo: name });
  }
  missing.sort((a, b) => a.path.localeCompare(b.path));
  return { orphans, conflicts, missing };
}

function renderInventory(ownership, home) {
  const rows = [...ownership.ownerByPath.entries()]
    .map(([p, repos]) => [p.replace(home, '~'), repos.join(',')])
    .sort((a, b) => a[0].localeCompare(b[0]));
  const lines = [
    '# dotsync inventory',
    '',
    '> Generated by `dotsync inventory`. Do not edit by hand; the manifest fragments are the source of truth.',
    '',
    '| Path | Owning repo |',
    '| --- | --- |',
    ...rows.map(([p, r]) => `| \`${p}\` | ${r} |`),
    '',
  ];
  return lines.join('\n');
}

function buildSyncPlan(repos, { force, hasOrphans }) {
  const blocked = hasOrphans && !force;
  const actions = repos.map((repo) => {
    const steps = repo.type === 'chezmoi'
      ? ['chezmoi re-add', 'git commit (if changes)', 'git push']
      : ['git add -A', 'git commit (if changes)', 'git push'];
    return { repo: repo.name, type: repo.type, steps };
  });
  return { blocked, actions };
}

// ---- IO scans --------------------------------------------------------------
function scanRoots(home, runner) {
  const found = new Set();
  // top-level $HOME dotfiles (entries directly under $HOME beginning with '.').
  // Symlinks are included because the work repo deploys its files via symlink.
  let entries = [];
  try { entries = fs.readdirSync(home, { withFileTypes: true }); } catch { entries = []; }
  for (const e of entries) {
    if ((e.isFile() || e.isSymbolicLink()) && e.name.startsWith('.')) found.add(path.join(home, e.name));
  }
  for (const dir of [path.join(home, '.config'), path.join(home, '.claude')]) {
    // -type l as well as -type f: the work repo deploys via symlink.
    const r = runner('find', [dir, '(', '-type', 'f', '-o', '-type', 'l', ')']);
    if (r.code === 0) for (const p of r.stdout.split('\n').map((s) => s.trim()).filter(Boolean)) found.add(p);
  }
  return [...found];
}

// ---- command handlers ------------------------------------------------------
function cmdCheck({ home, manifestDir, runner }) {
  const { repos, ignoreGlobs } = loadManifest(manifestDir, home);
  const ownership = buildOwnership(repos, home, runner);
  const existing = scanRoots(home, runner);
  const { orphans, conflicts, missing } = computeCheck({ ownership, existing, ignoreGlobs, home });
  for (const [name, errs] of ownership.errorsByRepo) for (const e of errs) console.error(`error[${name}]: ${e}`);
  if (orphans.length) { console.log(`orphans (${orphans.length}) — not in any repo, not ignored:`); for (const p of orphans) console.log(`  ${p.replace(home, '~')}`); }
  if (conflicts.length) { console.log(`conflicts (${conflicts.length}) — claimed by >=2 repos:`); for (const c of conflicts) console.log(`  ${c.path.replace(home, '~')} -> ${c.repos.join(', ')}`); }
  if (missing.length) { console.log(`missing (${missing.length}) — declared but absent on disk:`); for (const mm of missing) console.log(`  ${mm.path.replace(home, '~')} (${mm.repo})`); }
  if (!orphans.length && !conflicts.length && !missing.length) { console.log('check: clean'); return 0; }
  return 1;
}

function cmdStatus({ home, manifestDir, runner }) {
  const { repos } = loadManifest(manifestDir, home);
  for (const repo of repos) {
    console.log(`== ${repo.name} (${repo.type}) ${repo.path.replace(home, '~')} ==`);
    const sb = runner('git', ['-C', repo.path, 'status', '-sb']);
    process.stdout.write(sb.stdout);
    if (repo.type === 'chezmoi') {
      const diff = runner('chezmoi', ['diff', '--no-pager']);
      console.log(diff.stdout.trim() ? 'chezmoi diff: changes pending' : 'chezmoi diff: clean');
    }
  }
  return 0;
}

function cmdInventory({ home, manifestDir, runner }) {
  const { repos } = loadManifest(manifestDir, home);
  const ownership = buildOwnership(repos, home, runner);
  const out = expandTilde(INVENTORY_PATH, home);
  fs.mkdirSync(path.dirname(out), { recursive: true });
  fs.writeFileSync(out, renderInventory(ownership, home));
  console.log(`wrote ${out.replace(home, '~')} (${ownership.ownerByPath.size} entries)`);
  return 0;
}

function cmdSync({ home, manifestDir, runner, force, dryRun }) {
  const { repos, ignoreGlobs } = loadManifest(manifestDir, home);
  const ownership = buildOwnership(repos, home, runner);
  const existing = scanRoots(home, runner);
  const { orphans } = computeCheck({ ownership, existing, ignoreGlobs, home });
  const plan = buildSyncPlan(repos, { force, hasOrphans: orphans.length > 0 });
  if (plan.blocked) { console.error(`sync blocked: ${orphans.length} orphan(s). Re-run with --force to proceed.`); return 1; }
  cmdInventory({ home, manifestDir, runner });
  for (const action of plan.actions) {
    console.log(`== ${action.repo} (${action.type}) ==`);
    for (const step of action.steps) console.log(dryRun ? `  [dry-run] ${step}` : `  ${step}`);
    if (dryRun) continue;
    const repo = repos.find((r) => r.name === action.repo);
    if (repo.type === 'chezmoi') {
      runner('chezmoi', ['re-add']);
      runner('git', ['-C', repo.path, 'add', '-A']);
      const c = runner('git', ['-C', repo.path, 'commit', '-m', 'dotsync: capture config changes']);
      if (c.code !== 0 && !/nothing to commit/.test(c.stdout + c.stderr)) { console.error(c.stderr || c.stdout); return 1; }
      runner('git', ['-C', repo.path, 'push']);
    } else {
      runner('git', ['-C', repo.path, 'add', '-A']);
      const c = runner('git', ['-C', repo.path, 'commit', '-m', 'dotsync: capture config changes']);
      if (c.code !== 0 && !/nothing to commit/.test(c.stdout + c.stderr)) { console.error(c.stderr || c.stdout); return 1; }
      runner('git', ['-C', repo.path, 'push']);
    }
  }
  return 0;
}

// ---- arg dispatch ----------------------------------------------------------
function main(argv, env, runner) {
  const home = env.HOME || os.homedir();
  const manifestDir = expandTilde(MANIFEST_DIR_DEFAULT, home);
  const [, , sub, ...rest] = argv;
  const force = rest.includes('--force');
  const dryRun = rest.includes('--dry-run');
  switch (sub) {
    case 'check': return cmdCheck({ home, manifestDir, runner });
    case 'status': return cmdStatus({ home, manifestDir, runner });
    case 'inventory': return cmdInventory({ home, manifestDir, runner });
    case 'sync': return cmdSync({ home, manifestDir, runner, force, dryRun });
    default:
      console.error('usage: dotsync <check|status|inventory|sync> [--force] [--dry-run]');
      return 2;
  }
}

}
```
